## 1. 프로젝트 소개

**무엇을** — 휴대폰·태블릿에서 즐기는 7대7 3D 축구 게임 *Pocket Soccer 3D*의 화면 문구를 한국어로 옮긴 판본입니다. 게임 파일은 원본 그대로 두고, 화면에 그려지는 순간에만 문구를 한국어로 바꾸는 **표시 시점 오버레이** 방식이라 게임 로직·물리·저장 형식은 바뀌지 않습니다.

**왜** — 원본은 영어 UI만 제공합니다. 규칙(오프사이드·추가시간·승부차기), 조작, 전술, 통계 화면의 영어 문구를 매번 해석해야 해서 한국어 사용자가 게임의 규칙과 기능을 온전히 익히기 어렵습니다. 이 판본은 그 문구를 한국어로 옮겨, 같은 게임을 한국어로 바로 이해하며 즐길 수 있게 합니다.

**누구를 위해** — 모바일·태블릿에서 짧은 시간에 축구 게임을 즐기는 한국어 사용자, 특히 영어 UI 때문에 조작·규칙을 익히기 어려웠던 분들을 위해 만들었습니다. 기본 언어는 한국어이고, 화면 왼쪽 아래 **EN / 한국어** 버튼으로 언제든 영어 원문과 전환할 수 있습니다.

## 2. 주요 기능

### 원본 게임의 기능 (그대로 유지)

- 관절 애니메이션 선수, 실시간 그림자, 대형 전광판이 있는 3D 경기장
- 애니메이션 인트로 → 명예의 전당 → 이름 선택 → 메인 메뉴로 이어지는 흐름
- 전·후반 진영 교대, 스로인·코너킥·골킥
- 반칙과 프리킥, 수비 벽, 페널티킥, 경고·퇴장, 오프사이드, 심판
- 추가시간, 동점 시 승부차기
- 전술(포메이션·공격 성향·압박), 상대 팀의 포메이션 변화와 추격 플레이
- 체력과 전력 질주, 부상, 교체 3명
- 경기 종료 후 전체 경기 통계
- 골 장면 슬로모션 리플레이
- 난이도가 오르는 8개 레벨(하나를 이겨야 다음 레벨 해금)
- 선수 프로필, 자동 진행 저장, 진행 중인 경기 저장·이어하기
- 경기마다 주는 포인트와 기기 내 최고 점수표, 게임 내 도움말

### 한국어판이 더한 것

- 시작 화면, 명예의 전당, 이름 선택, 메인 메뉴, 조작 방법, 전술, 일시정지, 경기 종료·결과 화면의 문구를 한국어로 번역
- 경기 중 HUD(점수판·전·후반 표시·추가시간·반칙/카드/교체 안내), 경기 통계(점유율·슈팅·유효 슈팅·코너킥·오프사이드·경고·퇴장), 승부차기 안내, 저장/이어하기 문구 번역
- 3D 경기장 전광판 텍스처에 그려지는 글자까지 사전으로 번역
- 한글이 깨지지 않도록 시스템 한글 글꼴 우선 사용(Apple SD Gothic Neo → 맑은 고딕 → Noto Sans KR → Segoe UI). 웹폰트를 내려받지 않아 오프라인에서도 동일하게 보입니다.
- **EN / 한국어** 전환 버튼(기본 한국어)

## 4. 설치·실행 방법

정적 파일만으로 동작합니다. 게임 자체는 별도 빌드 도구가 필요 없습니다.

### 배포본 바로 열기

- 컴퓨터·모바일 브라우저에서 <https://sigco3111.github.io/soccer-3d-ko/> 를 엽니다.
- 휴대폰에서는 게임 메뉴의 **앱 설치** 또는 브라우저 메뉴의 *홈 화면에 추가*로 설치하면 전체 화면으로 실행되고 오프라인에서도 열립니다.

### 내려받아 실행

1. 이 저장소를 내려받습니다(`git clone` 또는 ZIP).
2. `python3 tools/patch_index.py` 를 실행하면 `_site/` 에 한국어 오버레이가 삽입된 배포본이 만들어집니다(원본 `index.html` 은 그대로 둡니다).
3. `_site/` 를 아무 정적 호스팅에 올리거나, 로컬에서 `python3 -m http.server` 로 열면 됩니다.

### GitHub Pages로 배포

`.github/workflows/pages.yml` 이 `tools/patch_index.py` 로 배포본을 만들어 GitHub Pages에 올립니다.

## 6. 기술 내용

- 원본은 **단일 자체 완결형 HTML 게임**이며 three.js r128을 CDN(cdnjs)에서 불러옵니다. 그 밖의 코드·사운드는 `index.html` 안에 들어 있습니다.
- 한글화는 **표시 시점 오버레이** 방식입니다. `ko/ko-overlay.js` 가 화면에 그려지는 순간에만 문구를 바꾸므로 게임 로직과 상태 저장 형식이 바뀌지 않습니다.
  - **DOM**: 요소 단위 문장 사전 + 대소문자 무시 사전 + 정규식 규칙(레벨·점수·경기 수 등 조립 문구)
  - **캔버스**: `fillText`/`strokeText` 를 감싸 사전 치환 + 한글 글꼴 적용(전광판 텍스처 포함)
  - **HUD**: 게임이 매 프레임 값을 덮어쓰는 자리를 놓치지 않도록 `textContent`·`innerHTML`·`createTextNode` 대입 시점에도 치환
- `tools/patch_index.py` 가 `ko/ko-overlay.js` 를 `index.html` 의 head에 인라인으로 넣어 `_site/` 를 만듭니다. GitHub Pages 배포는 `.github/workflows/pages.yml` 이 담당합니다.
- `manifest.webmanifest`·`sw.js`·`icons/` 로 설치형 오프라인 웹앱이 됩니다. `sw.js` 는 캐시 버전을 `ps3d-ko-v2` 로 올리고 오버레이 파일을 오프라인 캐시 목록에 추가했습니다(오프라인에서도 한국어 UI).
- 저장소 언어 구성(GitHub 집계): HTML 97.2%, JavaScript 2%, Python 0.8%.

## 9. 검증 기록

### 확인한 것 (2026-11-16, 배포 주소 <https://sigco3111.github.io/soccer-3d-ko/>)

- 배포 주소가 HTTP 200으로 열리고, 시작 화면부터 한국어로 표시됩니다.
- 시작 화면, 명예의 전당, 이름 입력, 메인 메뉴(레벨 목록·경기 시간·설정 토글), 조작 방법(전체 문단), 전술 화면, 일시정지 화면, 경기 중 HUD와 조작 버튼이 한국어로 표시됩니다.
- 점수판의 전·후반 표시가 "전반"으로, 상대 표기가 "vs 독사이드 주니어스"로 표시됩니다.
- 3D 경기장과 선수가 WebGL로 정상 렌더링되고, 조작 버튼(패스/달리기/슛)이 한글 글꼴로 깨지지 않습니다.
- 브라우저 콘솔 오류가 원본과 비교해 늘지 않았습니다(원본과 같은 three.js CDN 로드만 존재).

### 확인하지 못한 것

- **스크린샷**: 이 작업 환경의 확인용 브라우저가 화면 캡처를 지원하지 않아 README용 화면 이미지를 만들지 못했습니다. `docs/screenshots/` 는 비어 있으며, 화면 캡처는 소유자 기기에서 확인이 필요합니다.
- 경기 종료·결과 화면과 골·카드·부상·승부차기 문구는 실제 발생 시점까지 확인하지 못했습니다. 사전에는 포함되어 있으나 이벤트 발생 화면은 미확인입니다.
- 키보드 키 이름(Space·Shift·WASD·C)은 원문 표기를 유지했습니다.
- 시작 인트로의 큰 로고는 글자 하나하나가 개별 요소로 애니메이션되는 로고라 원문(POCKET SOCCER 3D)을 그대로 두었습니다.
- 팀 3글자 코드(DOC·MIL·RED 등)는 점수판 좌표용 약칭이라 원문을 유지했습니다.
