# 포켓 사커 3D 한국어판 (비공식 한글화)

7대7 3D 축구 게임 **Pocket Soccer 3D**의 화면 문구를 한국어로 옮긴 비공식 팬 한글화판입니다. 게임 규칙·물리·렌더링은 원본 그대로이고, 표시되는 글자와 글꼴만 바꿨습니다.

▶ 바로 플레이: **https://sigco3111.github.io/soccer-3d-ko/**

이 저장소는 비영리 팬 한글화이며 원작자와 무관한 비공식 작업입니다. 아래 [라이선스·원작 표기](#라이선스원작-표기)를 꼭 확인해 주세요.

## 무엇을 바꿨나

- 시작 화면, 명예의 전당, 이름 선택, 메인 메뉴, 조작 방법, 전술, 일시정지, 경기 종료·결과 화면의 문구를 한국어로 옮겼습니다.
- 경기 중 HUD(점수판·진영·추가시간·반칙/카드/교체 안내), 경기 통계(점유율·슈팅·유효 슈팅·코너킥·오프사이드·경고·퇴장), 승부차기 안내, 저장/이어하기 문구를 옮겼습니다.
- 경기장 전광판 문구(3D 텍스처에 그려지는 글자)까지 사전으로 바꿉니다.
- 한글이 깨지지 않도록 시스템 한글 글꼴을 우선 사용합니다(Apple SD Gothic Neo → 맑은 고딕 → Noto Sans KR → Segoe UI). 웹폰트를 내려받지 않습니다.
- 화면 왼쪽 아래 작은 **EN / 한국어** 버튼으로 영어 원문과 전환할 수 있습니다. 기본은 한국어입니다.

## 설치·실행

정적 파일만으로 동작합니다. 별도 빌드 도구가 필요 없습니다.

1. 이 저장소를 내려받습니다.
2. `python3 tools/patch_index.py` 를 실행하면 `_site/` 에 한국어 오버레이가 삽입된 배포본이 만들어집니다(원본 `index.html` 은 그대로 둡니다).
3. `_site/` 를 아무 정적 호스팅에 올리거나, 로컬에서 `python3 -m http.server` 로 열면 됩니다.

## 기술 내용

- 원본은 단일 자체 완결형 HTML 게임이며 three.js r128을 CDN에서 불러옵니다.
- 한글화는 **표시 시점 오버레이** 방식입니다. `ko/ko-overlay.js` 가 화면에 그려지는 순간에만 문구를 바꾸므로 게임 로직과 상태 저장 형식은 바뀌지 않습니다.
  - DOM: 요소 단위 문장 사전 + 대소문자 무시 사전 + 정규식 규칙(레벨·점수·경기 수 등 조립 문구)
  - 캔버스: `fillText`/`strokeText` 를 감싸 사전 치환 + 한글 글꼴 적용(전광판 텍스처 포함)
  - HUD: 게임이 매 프레임 값을 덮어쓰는 자리를 놓치지 않도록 `textContent`·`innerHTML`·`createTextNode` 대입 시점에도 치환합니다.
- `tools/patch_index.py` 가 `ko/ko-overlay.js` 를 `index.html` 의 head에 인라인으로 넣어 `_site/` 를 만듭니다. GitHub Pages 배포는 `.github/workflows/pages.yml` 이 담당합니다.
- `sw.js` 는 캐시 버전을 `ps3d-ko-v2` 로 올리고 오버레이 파일을 오프라인 캐시 목록에 추가했습니다(오프라인에서도 한국어 UI).

- 원작: **Pocket Soccer 3D (Soccer-3D)** — https://github.com/ShaunPrice/soccer-3d
- 원본 커밋: `96547fd` (2026-11-11)
- 원본 라이선스: **표기 없음** — 저장소에 LICENSE 파일이 없고, README·소스 헤더에도 라이선스 표기가 없습니다. 이 한글화 저장소는 원본에 라이선스가 있다고 주장하지 않으며, 어떤 라이선스 파일도 새로 만들지 않았습니다.
- 권리 상태: 원작자의 재배포 허락은 **확인되지 않았습니다(미확인)**. 이 저장소는 원작자 표기를 전제로 한 비공식 한글화이며, 원작자가 중단을 요청하면 즉시 비공개로 전환합니다.
- 에셋: 효과음·음성 해설과 시작 화면 아트워크는 원본 제작자가 **ElevenLabs** 생성물이라고 밝힌 자료입니다. 이 저장소는 원본 에셋을 임의로 바꾸거나 재배포 범위를 넓히지 않았고, 에셋에 대한 권리도 주장하지 않습니다. 에셋 권리는 별도 확인이 필요합니다.
- 이 저장소가 한 일은 화면 문구의 한국어 표시뿐이며, 원본 에셋과 게임 코드의 권리는 원작자(및 해당 생성 도구 제공자)에게 있습니다.

5. 분석용 파일(`_analysis/`, `tools/extract_*.py`, `tools/check_coverage.py`, `tools/extract_strings.py`) 추가 — 원문 문자열 추출과 번역 커버리지 점검 기록.
6. `README.md` 를 이 문서로 교체.

## 검증 기록

확인한 것(2026-11-16, 배포 주소 https://sigco3111.github.io/soccer-3d-ko/):

- 배포 주소가 HTTP 200으로 열리고, 시작 화면부터 한국어로 표시됩니다.
- 시작 화면, 명예의 전당, 이름 입력, 메인 메뉴(레벨 목록·경기 시간·설정 토글), 조작 방법(전체 문단), 전술 화면, 경기 중 HUD와 조작 버튼이 한국어로 표시됩니다.
- 3D 경기장과 선수가 WebGL로 정상 렌더링되고, 조작 버튼(패스/달리기/슛)이 한글 글꼴로 깨지지 않습니다.
- 브라우저 콘솔 오류가 원본과 비교해 늘지 않았습니다(원본과 같은 three.js CDN 로드만 존재).

확인하지 못한 것:

- 이 확인용 클라우드 브라우저에서 스크린샷 캡처가 되지 않아 README에 화면 이미지를 넣지 못했습니다(`docs/screenshots/` 비어 있음). 화면 캡처는 소유자 기기에서 확인이 필요합니다.
- 90분 전체 경기 진행, 골·카드·부상·교체·승부차기 같은 이벤트 문구는 실제 발생 시점까지 확인하지 못했습니다. 사전에는 포함되어 있으나 이벤트 발생 화면은 미확인입니다.
- 키보드 키 이름(Space·Shift·WASD·C)은 원문 표기를 유지했습니다.
- 시작 인트로의 큰 로고는 글자 하나하나가 개별 요소로 애니메이션되는 로고라 원문(POCKET SOCCER 3D)을 그대로 두었습니다.
- 팀 3글자 코드(DOC·MIL·RED 등)는 점수판 좌표용 약칭이라 원문을 유지했습니다.
